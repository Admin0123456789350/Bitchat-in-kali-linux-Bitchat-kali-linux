# Bitchat في Kali Linux

## 📋 نبذة عن المشروع

**Bitchat** هو تطبيق اتصالات آمن ولامركزي مصمم خصيصاً للعمل في بيئة **Kali Linux**. يوفر المشروع حلاً موثوقاً وآمناً للتواصل بين المستخدمين مع التركيز على الخصوصية والحماية.

## 🎯 الأهداف الرئيسية

- ✅ توفير منصة اتصالات آمنة وموثوقة
- ✅ ضمان الخصوصية الكاملة للمستخدمين
- ✅ دعم التشفير المتقدم للرسائل
- ✅ العمل بكفاءة على نظام Kali Linux
- ✅ واجهة مستخدم سهلة وبديهية

## 🚀 المميزات

- **التشفير الطرفي إلى الطرف**: رسائل مشفرة بالكامل لضمان عدم اعتراضها
- **لامركزي**: لا يعتمد على خوادم مركزية
- **خفيف الوزن**: استهلاك منخفض للموارد
- **آمن**: مبني على بروتوكولات أمان قوية
- **سهل الاستخدام**: واجهة بسيطة وسهلة التعلم
